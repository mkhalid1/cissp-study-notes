# CISSP Study Notes

A free, structured study guide for the ISC2 CISSP exam: how the adaptive exam works, a guide to each of the eight domains with the key concepts examiners test, 96 original practice items with full explanations, a 24-item diagnostic, how scoring really works, and plans for your final week or final two days. Written for working security and IT professionals, with a dedicated page on thinking like a manager, which is where most technical candidates lose marks. Facts about the exam come only from ISC2's own pages, each one [cited](docs/sources.md).

Want to see where you stand first? Take the [free timed CISSP practice test on PrepClubs](https://prepclubs.com/free-practice-tests/cissp?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=cissp), or the shorter [15-minute diagnostic](docs/diagnostic.md) in this repo.

## Start here

1. **Find your weak domains.** Take the [15-minute diagnostic](docs/diagnostic.md). It has three items from each domain and tells you where to start.
2. **Fix the weakest domain first.** Open its guide below, learn the key concepts and the method, then do its 12 practice items.
3. **Follow a plan.** Use the [7-day plan](docs/study-plans.md#7-day-plan) for your final week, or the [2-day plan](docs/study-plans.md#2-day-plan) if the exam is close.

## Quick facts

| | |
|---|---|
| Publisher | ISC2 |
| Exam outline | Effective April 15, 2024. A new outline takes effect April 15, 2027. |
| Format | Computerized Adaptive Testing (CAT) |
| Items | 100 to 150, including 25 unscored pretest items |
| Time | 3 hours maximum |
| Passing grade | 700 out of 1000 points |
| Going back | Not allowed. Every answer is final. |
| Languages | Chinese, English, German, Japanese, Spanish |
| Experience to certify | 5 years in 2 or more domains, up to 1 year waivable. Pass without it and you become an Associate of ISC2. |
| Pass rate | Not published by ISC2 |

Sources: [ISC2 exam outline](https://www.isc2.org/certifications/cissp/cissp-certification-exam-outline) and [ISC2 CAT page](https://www.isc2.org/certifications/cissp/cissp-cat), checked 24 November 2026.

## The eight domains at a glance

| Domain | Weight | What it is really about | Guide |
|---|---|---|---|
| 1. Security and Risk Management | 16% | Ethics, governance, risk maths, law, continuity planning, people | [Domain 1](docs/sections/security-and-risk-management.md) |
| 2. Asset Security | 10% | Classification, data roles, data states, sanitisation, retention | [Domain 2](docs/sections/asset-security.md) |
| 3. Security Architecture and Engineering | 13% | Design principles, security models, cryptography, facilities | [Domain 3](docs/sections/security-architecture-and-engineering.md) |
| 4. Communication and Network Security | 13% | OSI, secure protocols, segmentation, wireless, remote access | [Domain 4](docs/sections/communication-and-network-security.md) |
| 5. Identity and Access Management | 13% | Factors, biometrics, access models, federation, account lifecycle | [Domain 5](docs/sections/identity-and-access-management.md) |
| 6. Security Assessment and Testing | 12% | Scans, pentests, test techniques, SOC reports, metrics | [Domain 6](docs/sections/security-assessment-and-testing.md) |
| 7. Security Operations | 13% | Evidence, monitoring, incidents, change, backups, recovery, DR tests | [Domain 7](docs/sections/security-operations.md) |
| 8. Software Development Security | 10% | SDLC models, testing tools, coding weaknesses, acquired software | [Domain 8](docs/sections/software-development-security.md) |

Every domain guide has the same parts: what it covers (the official subdomains), key concepts, how the questions look, a step-by-step method, the traps that cost points, timing advice, 12 original practice items with explanations, and a score table.

## How to use this repo

- **Read on GitHub.** Every page has links to the previous page, the next page and back to these contents, so you can read it start to finish like a book.
- **Test yourself honestly.** Answers are hidden under "Answers and explanations". Commit to an answer before you open them.
- **Read every explanation,** including for items you got right. Each one says why the nearest wrong option loses, which is where CISSP points are won.
- **Keep a miss log.** For each miss, write why the right answer was better, not just correct. The [study plans](docs/study-plans.md#how-to-review-a-missed-item) show how.
- **Practise without going back.** The real exam does not allow review. A timed run, such as the [free one on PrepClubs](https://prepclubs.com/free-practice-tests/cissp?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=cissp), trains the pace.
- **Clone or fork it** to annotate your own copy. The structure also works as a GitBook space: see [SUMMARY.md](SUMMARY.md).

## About the practice items

All 96 domain practice items and 24 diagnostic items are original, written for these notes. None are taken from ISC2, from its official materials or from any prep site. They follow the published outline and the style of scenario judgement the exam rewards, so the reasoning you learn here transfers.
