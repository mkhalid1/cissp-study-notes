# The CISSP exam explained

The CISSP (Certified Information Systems Security Professional) is ISC2's credential for experienced security practitioners, managers and executives. The exam tests whether you can make sound security decisions across eight domains, from governance and risk through networks, identity and operations to software. It is broad by design: ISC2 wants a professional who can talk to the board in the morning and judge an architecture in the afternoon.

## Quick facts

| | What ISC2 says |
|---|---|
| Publisher | ISC2 |
| Current exam outline | Effective April 15, 2024 |
| Next exam outline | Effective April 15, 2027 |
| Format | Computerized Adaptive Testing (CAT) for all exams |
| Number of items | 100 to 150 |
| Time | 3 hours maximum, no minimum |
| Item format | Multiple choice and advanced item types |
| Passing grade | 700 out of 1000 points |
| Unscored items | 25 pretest items in every exam, which you cannot tell apart |
| Item review | Not allowed. Once you finalise an answer you cannot go back. |
| Languages | Chinese, English, German, Japanese, Spanish. Chinese is offered only in set windows: March, June, September and December. |
| Where | ISC2 Authorized Pearson Professional Centers and PVTC Select centres |
| Experience to certify | Five years cumulative, full-time, in two or more of the eight domains, with up to one year waivable |

Sources: [ISC2 CISSP exam outline page](https://www.isc2.org/certifications/cissp/cissp-certification-exam-outline) and [ISC2 CISSP CAT page](https://www.isc2.org/certifications/cissp/cissp-cat). Checked on 24 November 2026.

ISC2 calls these "average" weights. It does not publish how many items from each domain you will see on your exam, and with a variable-length adaptive exam the exact mix will differ from person to person. Treat the weights as a guide to where to spend study time: no domain is small enough to skip.

ISC2 also says that AI security is woven into all eight domains rather than treated as a separate topic: governing AI risk and bias, protecting training data and models, defending against prompt injection and data poisoning, managing AI agents as non-human identities, testing AI systems, and monitoring for model drift.

## How the adaptive exam works

CAT means the exam builds itself around you as you answer. ISC2 explains it like this:

1. Everyone starts with an item well below the passing standard.
2. After each answer, the system re-estimates your ability from the difficulty of every item so far and how you answered.
3. It then picks the next item so that you have roughly a 50% chance of getting it right.
4. As you answer more items, the estimate gets more precise.

Three consequences matter for how you prepare:

- **The exam will feel hard all the way through.** If you are doing well, the items get harder. ISC2 says everyone gets about half of the items they see right; what decides the result is how difficult the items you answer correctly are.
- **You cannot skip and come back.** There is no review. Every answer is final the moment you confirm it.
- **The length tells you nothing reliable.** Stopping at 100 items can mean a clear pass or a clear fail. The [scoring guide](scoring.md) explains the stopping rules.

## Who it is for

ISC2 lists roles such as Chief Information Security Officer, Chief Information Officer, Director of Security, IT Director or Manager, Security Systems Engineer, Security Analyst, Security Manager, Security Auditor, Security Architect, Security Consultant and Network Architect. ISC2 notes that the CISSP was the first information security credential to meet the ANAB ISO/IEC 17024 standard, and it is approved under the US Department of Defense directive DoDM 8140.03.

You can sit the exam before you have the full five years. If you pass without it, you become an **Associate of ISC2** and have six years to earn the experience. The [practitioners page](for-practitioners.md) covers the experience rules, waivers and endorsement.

## What the questions reward

The CISSP is not a test of the commands you type. Most items describe a situation and ask what you should do FIRST, which option is BEST, or what is MOST important. Several options are often technically correct. The right answer is the one a senior security professional would choose for the organisation, which usually means:

- people's safety first
- understand the business and the risk before choosing controls
- policy and management support before tools
- fix the root cause as well as the symptom
- advise and escalate; let the right owner decide

That mindset runs through every domain guide in these notes, and the [practitioners page](for-practitioners.md) works through it in detail.

## The April 2027 outline

ISC2 has published a new outline that takes effect on **April 15, 2027**. If you sit the exam before that date, study the current (April 2024) outline, which is what these notes follow. If you sit on or after it, check the new outline itself.

| Domain in the 2027 outline | Weight |
|---|---|
| 1. Security Governance and Risk Management | 13.6% |
| 2. Asset Security | 12% |
| 3. Security Architecture and Engineering | 12.8% |
| 4. Communication and Network Security | 12.8% |
| 5. Identity and Access Management (IAM) | 13.6% |
| 6. Security Assessment and Testing | 11.2% |
| 7. Security Operations | 12.8% |
| 8. Software Development Security | 11.2% |

The visible changes: Domain 1 is renamed to put governance first, the weights become more even (Domain 1 drops from 16% to 13.6%, Asset Security and Software Development Security rise), and the exam stays at 3 hours and 100 to 150 items. Source: [ISC2's 2027 CISSP exam outline (PDF)](https://edge.sitecorecloud.io/internationf173-xmc4e73-prodbc0f-9660/media/Project/ISC2/Main/Media/documents/exam-outlines/2027/EXAMS-CISSP-Exam-Outline-English-RB-Revised-1016-ENU-2.pdf).
